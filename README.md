# Trefaset vekselstrøm

Interaktivt undervisningsværktøj til trefaset vekselstrøm og elinstallationer (230/400 V, 50 Hz).

**Prøv det:** https://mtjdev82.github.io/trefase/

- **Grundteori** – 120° faseforskydning, RMS og spidsværdier, viserdiagram, nulstrøm ved usymmetrisk belastning.
- **Installation** – simulator fra transformer til brugsgenstand: TT, TN-C-S og lokal nulling, brud på nul og fase, dårlige samlinger, isolationsfejl, lækstrømme, HPFI-typer, AFDD, harmoniske og Ik,max/Ik,min. Indbygget måleinstrument (Zline, Zloop, Ub, RCD-test m.m.) og opgaver.
- **Vejledning** – forklaring af teori, model og målinger.

**Telefon og tablet:** virker i browseren på Android og iPhone/iPad og kan installeres som app på hjemmeskærmen (Android: Chrome → Installer app. iPhone/iPad: Safari → Del → Føj til hjemmeskærm). Efter første besøg virker den også uden net.

Ren HTML, CSS og JavaScript uden biblioteker eller build-trin. Åbn `index.html` i en browser for at køre det lokalt.
